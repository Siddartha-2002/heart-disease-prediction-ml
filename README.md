# Heart Disease Prediction Using Machine Learning

## Overview

Heart disease is one of the leading causes of death worldwide, making early detection essential for improving patient outcomes. This project explores how machine learning can be used to predict the presence of heart disease using clinical patient data.

The study investigates the research question:

> **To what extent can machine learning methods accurately predict heart disease using patient clinical features, and which model performs best?**

The project uses a comprehensive heart disease dataset containing patient information such as age, sex, chest pain type, cholesterol level, resting blood pressure, maximum heart rate, exercise-induced angina, oldpeak, and ST slope.

After preprocessing and exploratory data analysis, three machine learning models were developed and compared:

- Random Forest
- XGBoost
- Artificial Neural Network (ANN)

The models were evaluated using Accuracy, Precision, Recall, F1-score, ROC-AUC, Confusion Matrix, and ROC Curve.

Among the three models, **Random Forest achieved the best overall performance**, demonstrating that machine learning can effectively predict heart disease using structured clinical data and has the potential to support healthcare professionals in early risk assessment.
